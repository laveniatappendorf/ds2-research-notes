# About

These notes come from a personal, non-commercial research project on Dark Souls II.

## How they were made

The work was done by one person with the help of an AI assistant (Claude). The assistant read and compared game
data, traced code, ran some live checks, wrote up the results and translated Japanese developer text. A human chose the
questions and reviewed the results, but the notes have not all been independently checked. That is why every page has a
[status label](status-labels.md).

## Corrections and questions

Please open an issue on the repository if you find a mistake, can confirm or break a claim, or know a source that
settles something the notes leave open. Test results are especially welcome.
