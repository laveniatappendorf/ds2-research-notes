# Dark Souls II PS3: patch 1.01 -> 1.02 -> 1.03

!!! info "Status: From the data"
    Read straight from game files or compared between builds. What the files contain is checked; why they are that way (developer intent) is interpretation. See [status labels](../status-labels.md).

Comparison done 2026-10-23, following [v1.00 vs patch 1.01](v1.00-vs-1.01.md). Each step compares what the game loads in each build
(`DS2_GAME=v101` / `v102` / `v103`: that patch's PatchData over the v1.00 disc, 0-byte stubs falling back to the disc).
Tools as before, now with `--from <build>` (e.g. `tools\changed_files.py 1.03 --from v102`), plus
`regulation_fields.py` (per-field summary), `effect_compare.py` (effect scripts) and `tae_compare.py` (animation
events). Data: `regulation_1.01_vs_1.02.tsv`, `regulation_1.02_vs_1.03.tsv`, `changed_files_1.02_to_1.03.tsv`,
`text_1.02_to_1.03.txt`.

Names of enemies / NPCs are [the developers' Japanese AI-script labels](../network-test/nt-ai-labels-retail-enemies.md) translated literally; [brackets] = my
identification from other evidence.

## 1.01 -> 1.02: a balance patch (Calibrations 1.02 -> 1.03)

1.02 ships **1.01's PatchData byte for byte**: no game data, map, text or script changes. The program gains 256 bytes
of code (code end 0x17ee600 -> 0x17ee700, no readable string changes). Everything else is the regulation: 16 params,
**4,462 rows**.

- **Attack tracking cut** (WeaponAttackMotionParam, 1,190 rows): tracking at the start of an attack 1.0 -> 0.7 (762
  rows), in the middle 1.0 -> 0.3 (494), at the end 0.2 -> 0.1 (356): player attacks turn towards their target far
  less. Start-up and recovery speeds retuned both ways (507 / 485 rows).
- **Poise damage up**: DamageCtrlParam poise damage x1.8 in 1,135 rows (15 -> 27, 22.5 -> 40.5 ...), 207 rows switch
  stagger mode 0 -> 1; every weapon's PvP poise damage up (324 weapons, median x1.5, e.g. Dagger 2 -> 3.5); twinblades'
  PvE poise damage 1 -> 2.5.
- **Counter hits weaker**: PlayerDamageParam counter-damage multiplier 1.0 -> 0.91 (303 attacks) or 0.8 (31);
  knockback, stamina damage and hitbox sizes retuned (hitbox length cut in 127 rows).
- **Parry windows**: 72 weapons, mostly longer (Dagger 0.675 -> 0.72 s; 61 up, 11 down).
- **Spells**: cast speed up for 120 spells (median x1.3), start-up faster for 119, stamina costs mostly down (61 of
  85); damage multipliers changed (Soul Spear 1.25 -> 1.5, Crystal Soul Spear 1.5 -> 1.75, Dark Orb 1.25 -> 1.4, Soul
  Greatsword 2.0 -> 1.9).
- **NG+**: ChrRoundDamageParam stamina-damage multipliers raised for every cycle (e.g. NG+1 120 -> up to 200, NG+4
  150 -> up to 500); 279 enemies switched to new NG+ profiles (EnemyParam round-damage id +10 / +20).
- Weapons: chain and falling attacks re-pointed for 145 weapon categories; Strength scaling slightly down for 10
  scaling tables (Drakekeeper's Ultra Greatsword ...); Light / Heavy / Shield Crossbow and Avelyn moved to scaling table
  2000000; **powerstance (L1 / L2) bolts 0.686 -> 0.882** (PlayerDamageParam 609x0060 / 609x0070, all bolt types;
  normal crossbow shots, Avelyn's included, stay 0.98; [Mundane at SL50](../mechanics/mundane-sl50-v100.md), 2026-11-01); bows retuned (Dragonrider Bow stamina 212 -> 290).
- Armour: **Black Dragon set** weight cut to a third (Armor 14.5 -> 4.8), Strength / Dexterity requirements 14 -> 0,
  poise -> 0, elemental absorption x2.2 (kept in 1.03 and [on the PS3 Scholar disc](balance-vanilla-vs-scholar.md#4-armour-and-rings)); Ironclad Armor and
  Old Ironclad Armor weight 16.8 -> 29.8; Monastery Headcloth slash / thrust defence 14 -> 28.
- Items: Witching / Lightning Urn, Firebomb, Black Firebomb and one more throwable animation speed 1.0 -> 0.85;
  Poison Moss 0.75 -> 1.3 and a new item type 350.
- Guard motions: GuardLevelMotionParam rows 10002 / 10003 / 10102 / 10103.

## 1.02 -> 1.03: data, scripts and a second balance pass (Calibrations 1.03 -> 1.04)

Data built 1 Apr 2014 (three weeks after launch). Of 3,058 files: 91 really change, 51 are the cut talk / text files
no longer listed (the disc copies, identical, stay in use: [cut talk timeline](cut-talk-timeline.md)), **nothing from 1.01 is reverted**.
The program grows 22 KB (code end 0x17f3d00, TOC 0x1d3f570).

### Regulation (28 params, 5,164 rows; 252 -> 247 params)

- **Equipment wear from enemies cut**: EnemyDamageParam durability-damage multiplier x0.8 in **4,921 rows** (5 -> 4,
  10 -> 8).
- Weapons: recovery animation weight x0.75 for 33 weapons (Murakumo, Arced Sword, Curved Dragon Greatsword,
  Zweihander ...); twinblades' durability x2-3 (Twinblade 50 -> 150).
- **Moonlight Greatsword**: its light, running and power-stance attacks re-pointed to new motion / damage rows
  (10038810, 10039910, 10041410) and its item effect type 3 -> 0. **Soul Greatsword** (spell): two new bullet / damage
  rows 31140010 / 31140020.
- **Miracles**: Heal, Med Heal, Great Heal Excerpt, Great Heal ... start up much faster (1.2 -> 0.65) and cast faster
  (1.5 -> 0.9-1.2). **Firestorm, Fire Tempest, Chaos Storm**: start-up duration x3 (0.125 -> 0.375 s).
- Movement: ChrMoveParam 100 walk acceleration 20 -> 50, lock-on walk acceleration 25 -> 50, auto-walk speed
  0.1 -> 0.5. Equip load (ChrEquipLoadParam row 2): breakpoints 30 / 70 / 100% -> 21 / 49 / 70%; row 25 31.5 / 45 ->
  28 / 40. Which rows the player uses not checked.
- Enemies:
  - 異形の影（生者） "deformed shadow (living)" (123002 / 123022): HP 560 -> 330, damage to players x0.65.
  - アンデッド市民：爆発 "undead citizen: explosion" (125004-125016): HP cut to a third (250 -> 80 ...), stamina
    1,740 -> 435, poise 4,400 -> 0.
  - Weaker defences (absorption down, so they take more damage): マンスコーピオン♀ "female man-scorpion"
    [Scorpioness Najka] 1.0-1.35 -> 0.57; 月光爺 "moonlight old man" 1.0 -> 0.66; 女騎士 "female knight"
    [Lucatiel] 0.85 -> 0.42.
  - 忘れられた罪人 "the forgotten sinner" [the Lost Sinner]: recovery of two move groups slowed (x0.6, x0.85).
  - 52 attacks of enemy 1123xx damage ~4% lower, knockback faster.
  - **[57 short-id EnemyParam rows removed](v1.00-only-content.md#removed-in-103-data-1-apr-2014)**: 2235 Royal Rat Authority, 3050 Smelter Demon, 3096 The Last Giant,
    3180 / 3181 The Pursuer, 3260 The Rotten, 3320 Throne Defender, 5030 Scorpioness Najka (ids = their character
    numbers), 8100 and 9100-9648. One new row 119001 獅子黒魔道士（生者） "lion black sorcerer (living)"; 10 new
    [EnemyCommonParam rows (650000-660000, 812000)](early-pc-builds.md#dlc-enemies-in-the-spring-2014-builds).
- **Online areas** (NetworkAreaParam): removes 10030000, 10110000, 10280000 (m10_03 / m10_11 = [the working numbers](../unused/unused-map-pieces.md#patterns) of
  Dark Chasm / Shrine of Amana, m10_28 = [the cut "Firelink Throne"](../unused/unused-models.md); earlier notes), adds 10290000, 10300000, 20260000
  (Dragon Memories), 30190100. Part of the same clean-up of cut maps as the talk files.
- Regulation drops ItemLotParam, ItemLotParam2, ItemLotTicketParam, ItemLotWeightParam and regulationPortuguese.fmg.
- Smaller: Gyrm Warrior Greathelm (weight 7.9 -> 9.6, poise 16 -> 24, defences +30%), Corrosive Urn, 6 new pad-rumble
  rows, ResultEventParam 301-304 flag, NetworkParam 30 -> 45, a falling-attack set re-pointed (category 3500).

### Effect scripts

- Homing Soulmass (events 31070090-99): one argument 5 -> 6 in each.
- Corrosive Urn effect 60610010: two values -10 -> -5 and a third entry (-10) added.

### NPCs, maps and events

- [奇跡の人 "miracle person"](jp-disc-vs-us.md#2-what-changed-173-of-11457-files-1-repack) (Majula generator 150; [probably Licia of Lindeldt], the enemy 1.01 buffed): new death
  event 15000 (new EventParam row).
- 熔鉄デーモン "molten-iron demon" [Smelter Demon] (Iron Keep generator 807): appearance / death events re-wired
  (appearance 15020 -> 119000088, death 14000 -> 15020).
- 月光爺 "moonlight old man" (Memories generator 656): new death event 20000.
- Majula spawn table drops two 鷹匠戦士 "falconer warrior" entries (313021 / 313031).
- **11 maps' event scripts gain OBJからキャラをデタッチ "detach character from object"** (Things Betwixt, Majula,
  Forest of Fallen Giants, Aldia's Keep, Lost Bastille, No-man's Wharf, Iron Keep, Huntsman's Copse, the Gutter,
  Memories, Drangleic Castle); Majula also gains host / guest / global-flag states, Drangleic Castle a "golem
  instance ID".
- Prefab o18_1010 changed; no MSB, collision or map-model changes.

### Player animations (c000100_pl.tae, first shipped in 1.03)

73 of 1,097 animations really change, all attack movesets (2003xxxx-4603xxxx): a new type-2300 window (3-5 frames,
parameter 1) early in 72 places, 24 new type-300100 events, and timing / parameter edits to types 101100, 120200,
111600, 111400, 120300. **Roll, backstep and landing (the i-frame animations of [roll i-frames and Agility](../mechanics/agility-iframes.md)) are unchanged**:
their invincibility events 110100 / 110300 are identical. (A naive diff shows 549 changed animations: the file grew,
so every internal offset moved; `tae_compare.py` follows offsets.) The player's animation network (c0001.nmb) also
changes again.

### Text

- **Dark attribute bonus** (iconHelp 909190): "scales with the **higher** of these two attributes" -> "**lower**",
  English and Japanese. **Text fix only** (checked 2026-11-01): the v1.00 stat builder (`FUN_008609f0`, block
  0x8614a4-0x861514) already picks the lower of INT (attrs +0xc) and FTH (+0xe) (`cmpw FTH, INT`; keeps INT only when
  FTH > INT) as the PhysicalStats row for `stat_dark_bonus` (+0x20 -> out +0x3c); the same 13 instructions are
  byte-identical in 1.01 (0x868f04), 1.03 (0x86cd54) and 1.10 (0x8a99e4). Fire is floor((INT + FTH) / 2) in every
  build (0x8613b0). Details: [Mundane at SL50](../mechanics/mundane-sl50-v100.md).
- New message for equipping a ring that conflicts with another ring ("Cannot equip. This ring conflicts with another
  equipped ring.", replacing a stats message in that slot).
- New event message 4040 "The nature of your being has changed" (Japanese 新たな性に変化した, "changed to a new sex").
- Japanese "the Estus Flask's power was raised" -> "by some power, the Estus Flask's power was raised".
- The Steam / frame-rate messages 1.01 added in English and Japanese get their other 8 languages (were "none text").
- Info URL players.darksouls.jp -> info.darksouls.jp; Dark Fog "breath" -> "breathe"; a Japanese talk typo
  (礼変わり -> 礼代わり); 97 Japanese item-name slots filled with 空き "empty".
