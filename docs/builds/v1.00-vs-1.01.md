# Dark Souls II PS3: v1.00 vs patch 1.01

!!! info "Status: From the data"
    Read straight from game files or compared between builds. What the files contain is checked; why they are that way (developer intent) is interpretation. See [status labels](../status-labels.md).

Comparison done 2026-10-23 for the author (1.01 is [the version PC launched with](cut-text-on-pc.md#answer)). v1.00 = the US disc (data built 27 Jan
2014); 1.01 = the first title update (data built 24 Feb 2014, two weeks before the 11 March launch). Patch 1.02
reuses 1.01's game data byte for byte (new program and regulation only), so everything below in game data holds for
1.02 too.

Tools (all in `tools\`, run with `uv run --no-project --python 3.12 python -I -X utf8 tools\<tool> 1.01`):
`changed_files.py` (every PatchData file classed; `changed_files_1.01.tsv`), `regulation_compare.py`
(`regulation_1.00_vs_1.01.tsv`), `text_compare.py` (`text_1.01_english.txt`), `mapparam_compare.py`, `msb_compare.py`,
`pair_compare.py` (pieces inside split archives), `ainames.py` (developers' AI script labels, `ai_labels.json`).
Shared: `DS2_GAME=v101` (games.py) reads PatchData over the v1.00 disc.

Enemy and NPC names below are [the developers' Japanese AI-script labels](../network-test/nt-ai-labels-retail-enemies.md), translated literally; an English name in
brackets is an identification made from other evidence (noted), not part of the label.

## 1. What the patch really changes

1.01's PatchData lists 3,054 files, but most are not changes:

| Class | Files | Meaning |
|---|---|---|
| stub | 1,442 | 0-byte entry over a non-empty disc file: the game falls back to the disc copy (every character's sound bank, texture and camera binder is stubbed; they cannot really be empty) |
| identical | 1,368 | byte-identical copy of the disc file (whole text and param folders re-shipped) |
| **changed** | **243** | real changes (below) |
| repack | 1 | `c7530.texbnd`: same textures, rebuilt binder |

The 1.01 program is what makes this work: **v1.00's EBOOT has no patch layer at all** (mounts `map:`, `parts:`,
`title:`, `menu:`); 1.01's adds `patch:/PatchData.bhd` and the mounts `gamedata_patch:`, `patch_binder:` (chr
textures, AI scripts, objects, equipment parts, animations) and `title_patch:` (regulation, shaders, sfx, server list,
key config). Per-category lookup explains the stubs.

## 2. Balance (regulation, Calibrations 1.00 -> 1.02) and effect scripts

9 of 252 params change (54 rows, 4 new rows); plus 2 effect scripts:

- **Chloranthy Ring** stamina regeneration x1.035 / x1.055 / x1.085 -> **x1.15 / x1.20 / x1.25** (+0 / +1 / +2;
  `SpEffectRing.emevd`).
- **Green Blossom** stamina regeneration for 60 s x1.07 -> **x1.15** (`SpEffectActiveItem.emevd`).
- Enemy 769000 (下位：奇跡の人 "miracle person", unidentified NPC): HP 2,440 -> **4,580** (NG+7 9,736 -> 18,275),
  physical defence 338 -> 581, souls 1,000 -> 2,500, damage x1.0 -> **x1.68**.
- Enemy attack set 160201010-160201040 (no AI label): damage cut 10-50% (256 -> 224, 496 -> 352, 736 -> 672,
  656 -> 352).
- Enemy projectile 177100510/511 reworked: the volley (3 shots, spread, homing, 396 / 198 damage, hit sfx 5290) becomes
  a single straight bullet with 0 damage that spawns two new child bullets (new rows 177100512/513 in EnemyBulletParam
  and EnemyDamageParam); 177001331/332 lose online visibility 2.
- Lightning Spear, Great Lightning Spear, Sunlight Spear (and NPC versions 7214-7216xxxx, plus 31170010-13): BulletParam
  flag Unk14 1 -> 0 (31170010-13 also Unk16 / Unk17 0 -> 1); meaning unknown.
- EnemyDamageParam 112402810 / 112402910: damage control id 540501118 -> 540502101.
- EnemyParam field Unk02 1 -> 2 for 9 enemies: 106001 ダークプリースト（亡者） "dark priest (hollow)", 127002 死者の労働：３倍速
  "labour of the dead: triple speed", 132022 スケルトン skeleton, 133001 車輪スケルトン wheel skeleton, 137021
  ネクロマンサー（イモータル） "necromancer (immortal)", 147004 亡者_病人の服 "hollow in sick-person's clothes",
  [157003 / 157013 / 157022](damage-calculator-vanilla.md#enemies-sheet) (no label).
- Items: **Ladder Miniature** use id 2700 -> 2230; **Hello / Thank You / I'm Sorry / Very Good! Carvings** sell price
  200 -> 0.
- Bonfires: Gyrm's Respite + Ordeal's End (Doors of Pharros) get lit flag 100967, Grave Entrance + Harval's Resting
  Place (Grave of Saints) lit flag 100965 (were 0).
- Character creation: FaceEditParam 97 / 98 / 100 slider ranges widened (-0.4..0.4 -> -1..1, -0.3..0.4 -> -1..1,
  0.1..1 -> 0.01..2).
- NetworkParam: two online timings 5 -> 6 and 10 -> 18. EnemyEquipWeaponParam 30810000 first word changed.

Full list: `regulation_1.00_vs_1.01.tsv`.

## 3. NPCs and enemies (AI scripts, map params, models)

- **Bell Keepers (鐘守), the PvP covenant's NPC invaders, reworked.** New character model c7530 (mesh, cloth
  physics) and every Bell Keeper armour piece (model 7530: head / body / arms / legs, both sexes, both detail levels);
  the Lost Bastille (Belfry Luna) and Iron Keep (Belfry Sol) event scripts gain a shared library for them
  ("bell-ringing lever: navigation change", "... guest condition", "passable", "waiting for the door to open"), and
  each map gets one new event region in its belfry (EventLocation m10_16 400000, m10_19 1000000).
- **New AI state 【攻撃】回避キャンセル "attack: evasion cancel"** added to all 16 changed AI scripts: 両面戦士：ヘビ頭
  "two-sided warrior: snake head", デュラハン "dullahan", ベイグランド "Vagrant" ([the Pursuer's working name](../network-test/boss-region-names.md#the-pursuer-was-vagrant), earlier
  notes), [鏡の中の戦士 "warrior in the mirror"](../network-test/mirror-names.md#2-the-ruin-sentinels-c3250) (+ "random movement"), マンスコーピオン（男） "man-scorpion (male)" [Tark],
  墓守 "grave warden", 蜘蛛の女王 "spider queen" [Freja] (+ "front turn method / direction check", "stunned wait"),
  重騎馬兵：兵士のみ "heavy cavalry: soldier only" [Dragonrider], 王国隊長 "kingdom captain" and its white-phantom
  version, 月光爺 "moonlight old man", パッチ "Patches", 女騎士 "female knight", 封じられた人 "sealed person", and the
  generic white-phantom (summon) AI.
- **封じられた人 "sealed person" learns ladders**: new states for ladder climbing (梯子昇降, 【LIB】梯子移動, "use start /
  end / fail", "upper / lower attack", "nav search"). The 1.01 EBOOT also drops the string `InitLadder`.
- **Generic summon AI**: new state 白扉失敗 "white door failure" (a summon failing to pass a fog door).
- **梯子屋 "ladder shop" [Gilligan, who sells ladders]**: his Majula generator gets a new death ("grave") event 111099
  (new EventParam row, flag 10044000) and its two hostility events swap order; the Ladder Miniature item changes too.
- **呪術屋 "pyromancy shop" [Rosabeth]**: her Majula line "Goodness, are you alright?" is muted (audio 99999999,
  subtitle hidden) in m10_04 and m10_29.
- **Manscorpion Tark**: talk row 50200700 ("Since I speak the tongue of men, does this mean I was once human?") now
  plays "The past is a distant fog..." and the old row for that line is removed.
- **ＥＸ鍛冶屋 "EX blacksmith" [McDuff, the Lost Bastille smith]**: generator field Unk0C 3 -> 0.
- Majula event script: new checks 出現判定 "appearance check" and ナーガ撃破判定 "Naga defeated check".
- Aldia's Keep event script gains "hostile spirit" (敵対霊, i.e. invader) versions of its enemy-activation, navigation-
  change and 壁破壊オーガ "wall-breaking ogre" activation states, one "navmesh switch only" ogre state, and a
  敵の反応しない霊体 "phantom that enemies don't react to" label.
- Animation networks (.nmb) changed for c0001 (the player), c1020 王国兵士（亡者） "kingdom soldier (hollow)" and c1250
  アンデッド市民 "undead citizen". Event scripts of Forest of Fallen Giants and the Gutter change slightly (no new state
  names).

## 4. Maps

- Collision: 21 pieces in 8 maps re-baked (`pair_compare.py`; each map's .acb asset binder changes with them):
  Forest of Fallen Giants 2, Lost Bastille 4, Iron Keep 2, Dragon Aerie 3, Heide's Tower 3, Shaded Woods 2,
  Memories (m20_10) 1, Drangleic Castle 4.
- Layout (MSB): No-man's Wharf: 6 collision parts (h03_8000-8501) gain bit 16 of word +0xd0; Shaded Woods: one new
  event 背景色 "background colour".
- Memories of the giants (m20_10): objects o10_1050 and o10_2400 (one copy each, only used there) changed, plus its
  map-model and collision asset binders and its graphics filter (`filter_m20_10_00_00.fltparam`).
- Drangleic Castle: map piece m7000 changed (same size).

## 5. Text

17 English files change. Every change is a fix, a placeholder removal or new system text:
- **Steam strings in a PS3 patch**: IngameSystem 20007 "Lost connection to Steam. Switching to offline mode..." and
  20008 "Frame rate unsuitable for online play. Switching to offline mode..." (all languages): the PC port's text
  shipped two months before PC's 25 April 2014 release.
- Northern Ritual Band: "Increases spell uses" -> "Increases spell uses, **but at the cost of HP**". Neither its effect
  script nor any param changes in 1.01, so this corrects the description of an existing cost.
- Imperious set (four pieces): "Relics of a party who long ago long ago" duplicate fixed.
- common 50000010 "Player" -> "online ID".
- Placeholder subtitles "(no line)", "(N/A)", "(scream of death; no subtitle)", "(字幕なし）" deleted in the talk
  files of 11 maps and replaced with "..." in Dragon Aerie (6 lines), Undead Crypt (1) and Drangleic Castle (1 of
  its 6): dying screams and silent lines no longer show placeholder text.
- Japanese: Ornifex's line about the king used ヴェンドリック (the English name "Vendrick" in katakana) -> ヴァンクラッド
  (Vanclad, his Japanese name); 召還 -> 召喚 (summon); 古龍 -> 古竜 (Drakewing Ultra Greatsword); covenant message 古龍の誓約
  -> ＜古竜の片鱗＞ (named covenant); particle typos in the Desert Sorceress set and Ashen Mist Heart descriptions;
  "Mild" -> "MILD".
- Two "none text (ID ...)" placeholders added to TitleFlow; 23 French blood-message lines change (not read).

## 6. Program (EBOOT)

Code grows 44 KB (0x10000-0x17e3900 -> 0x17ee600; TOC 0x1d1f068 -> 0x1d2f3e8). Readable string changes:
- the patch layer (section 1);
- online content file `http://frpg2-ps3-internal.s3-website-us-west-2.amazonaws.com/contents_0101.bin` ->
  `contents_0105.bin`;
- build path `n:/dantelion2_localbuild/...` -> `n:/Stable_10_0_FRPG2_Title/...` (1.01 built from a "Stable_10_0"
  branch);
- new `invaded_count`; gone `InitLadder`, `gamedata:/model/weapon`.
No code-level diff yet.
