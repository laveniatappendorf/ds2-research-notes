## 1. Read order: there is no single order

From 1.08 a patch ships two archives, `PatchData` (mounted as `patch:` / `patch_binder:` / `gamedata_patch:`) and
`DlcData` (`dlc_catalog:/DlcData.bhd`, files as `dlc_data:/...`). The 1.10 program (= the PS3 Scholar program) does
not search them in a fixed order. **Every file type has its own resolver that picks one mount, often by id**
(addresses in the 1.10 EBOOT):

- **AI scripts** (`0xa5ff38`): id < 0 -> the disc's `ai009999`; if test T is true -> `dlc_data:/ezstate/ai%06d.esd`;
  else a hard-coded list of AI ids (603020, 611000, 724000, 744000, ... = the AIs the patches changed) ->
  `patch_binder:`, a few DLC id ranges -> `dlc_data:`, everything else -> the disc's `ezstate:`.
- **Character time-acts** (`0x4d39c0`): the player (c000100) -> always `patch_binder:`; if T -> `dlc_data:`; else
  DLC enemy ranges 650000-699999 and 860000-899999 (and 305020) -> `dlc_data:`; else the disc.
- **Map files** (navmesh, params, scripts ...; chooser `0x8fb7b0(map, file type)`): DLC maps (area 50) -> always
  `dlc_data:`; if T -> a per-file-type table (`0x187bd90`: types 0-4, 7-9, 14-21 yes; 5, 6, 10-13 no) sends that type
  to `dlc_data:` **for every map**; else only the four maps m10_19 Iron Keep, m10_25 the Gutter, m10_32 Shaded
  Woods (the three DLC entrances) and m20_24 Undead Crypt can use `dlc_data:` (a further per-map check, not read);
  otherwise `patch_binder:` / `map:`.
- **Test T** (`0x2b2408`): a global object's +0x60 field, asked (virtually) for a number; true if > 10299. The DLC
  archives' index headers carry `00010200` (1.08) and `00010300` (1.10 = Scholar): **T flips from false to true at
  1.10**, which fits T = "DLC catalog version >= 1.03". Not proven: the object is not identified, and whether it is set
  in vanilla without DLC licences is not known.

So 1.08 / 1.09 behave like "PatchData first, DlcData for DLC content and the four entrance maps", and 1.10 like
"DlcData first" for AI, enemy time-acts and most map file types. The profiles use exactly that (1.08 / 1.09 PatchData
first, 1.10 DlcData first); it is exact for files present in only one archive and approximate for files in both with
different bytes (15 in 1.08, 78 in 1.10, mostly event scripts of the DLC-entrance maps). From 1.10, DlcData carries a
complete copy of every enemy time-act (1,312) and AI script (1,168): from then on the DLC archive is the main store
of game logic, with PatchData for the player and base-game text / params.

Data evidence that agrees: where the two archives both hold a stamped binder with different bytes, the DlcData copy
is newer (2 of 2 in each build); the PS3 Scholar disc's GameData (built 78 min after 1.10's PatchData) matches
1.10's PatchData copy for all 78 overlaps; 1.09's PARAM.SFO says `TARGET_APP_VER 01.08` (it installs only on top of
1.08 and relies on its DlcData).

## 2. 1.08 -> 1.09 (data built 8 Oct 2014): a small fix patch

- Online content `contents_0112.bin` -> `contents_0113.bin`; program 1,280 bytes smaller (code end 0x1845d00 ->
  0x1845800).
- **Ivory King Ultra Greatsword**: its ice-wave attacks' projectile chains cut (child bullets removed, lifetimes
  0.7 -> 0.5, 0.6 -> 0.4, 0.2 -> 0.1 s; the two swing motions re-pointed). Plus one EventCommonParam and one
  EventFlagListParam row. 7 regulation rows in all (Calibrations 1.11 -> 1.12).
- New message (all languages): "Beg for pardon? Souls needed: 0" (mapevent 1221).
- Brightstone Cove Tseldora's talk script gains states "detach character from object", "reset count", "warp object to
  point", "push / pop light filter", "push / pop volume-fog filter".
- Player time-act: three animations (3203xxxx) move their type-2300 window 0.1-0.3 s later; the rest of the 111
  "changed" animations only lose stale bytes (the low three bytes of 143 words zeroed: an exporter clean-up). Roll /
  backstep / landing unchanged.

## 3. 1.09 -> 1.10 (data built 26 Nov 2014, with Scholar): two layers

### 3a. The base-game patch archive (PatchData 1.09 -> 1.10; independent of the read order)

- **Aldia is in vanilla 1.10's own PatchData**: 8 spawn points (generator rows 910-917 in m10_14 Tseldora, m10_16
  Lost Bastille, m10_19 Iron Keep, m10_25 the Gutter, m10_27 Dragon Aerie, m20_21 Drangleic Castle x2, m20_24 Undead
  Crypt, registering enemies 693000 / 692000), about 50 lines of his dialogue per map in all 11 languages (talk ids
  692000xx, e.g. "Young Hollow, there are but two paths. Inherit the order of this world, or destroy it."), and the name
  "Aldia, Scholar of the First Sin" (charaname 6920). His enemy rows are in the 1.10 regulation. The same 8 spawns
  are [the PS3 Scholar disc's](enemy-counts-v110-vs-pc.md#method) (`..\..\DS2 Scholar` notes). **Whether he actually appears in vanilla 1.10 (spawn
  conditions, event flags) is not checked**: a live test in RPCS3 would settle it.
- Per-map params: GeneratorParam in 23 maps, EventLocation / EventParam in 10, MapObjectInstanceParam in 8,
  GeneratorLocation / GeneratorDbgLocation / GeneratorRegistParam / NpcTalkParam in 7; 3 new demo params
  (scn202150).
- Effect scripts: Rouge Water, Crimson Water, Rusted Coin, Sanctum Knight Leggings, Shield of the Insolent,
  Slumbering Dragon Shield, Blossom Kite Shield changed; new events for the **Agape Ring**, **Watchdragon Parma** and
  six enemy effects 96920000-96920050 (the 6920 = Aldia number) and one wide-use effect.
- Text (217 files): Aldia's dialogue (above), the **staff roll** rewritten (1,449 lines per language), title menu (36
  English entries), bonfire / key-guide / item text, Portuguese fixes. Menus: the title screen gains a texture
  `Title_Best_DC.tpf`, and the end-credits screen changes.
- Program: **= the PS3 Scholar EBOOT** (byte-identical decrypted); online content `contents_0113.bin` ->
  `contents_0114.bin`; new `dlc_data:` mounts for sound.
- Regulation (Calibrations 1.12 -> 1.13; **= the Scholar disc's**, details in [the Scholar balance notes](balance-vanilla-vs-scholar.md)): 44 params,
  1,207 rows changed, 282 new rows. 249 -> 221 params: 28 legacy params dropped (PlayerAttackParam, CameraParam,
  StaminaParam, UnitTestParam ...) and the four item-lot params 1.03 removed come back. Highlights: **co-op summon
  time per kill cut by a third** for 606 enemies (90 -> 60, 18 -> 12, 180 -> 120; 45 to 0); enemy detection distances
  (LogicComParam, 125 rows); debug start-status items (DbgPlayerStatusParam); bonfire, boss-battle and event-flag
  rows; new rows for Aldia (EnemyParam 692000 / 693000, his weapons and behaviour), the Agape Ring, 13 item lots
  (6004xxxx boss rewards ...); Ivory King armour price x10.

### 3b. The DLC archive (DlcData 1.08 -> 1.10, version 1.02 -> 1.03; = the Scholar disc's DlcData)

It grows from DLC content into a full store of game logic: +1,021 time-acts, +466 AI / event script pairs (115
changed), +291 params (29 changed), +268 prefabs, +20 base-map layouts (MSB; 1.08 had the 4 DLC maps plus exactly
the 4 base maps the chooser lists, m10_19 / m10_25 / m10_32 / m20_24: code and data agree), +20 navmeshes, +20 filters, +77 sound banks, +28 menu textures; the MSBs of m10_19, m10_25,
m20_24 and m50_35 and a few models / collisions changed. With test T true (section 1) these copies
win for AI, enemy time-acts and most map file types, so in a DLC-active 1.10 the base maps' layouts, params and
scripts come from this Scholar-era copy (it also carries the Aldia spawns). In the full comparison
(`changed_files_1.09_to_1.10.tsv`, DlcData-first model) 1,544 files change, 79 are new and 28 revert to the disc copy;
190 of the changes come with a PatchData -> DlcData switch of source and depend on that model.
