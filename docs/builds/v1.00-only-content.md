# Content in PS3 v1.00 that is gone by patch 1.03 and was not in the Network Test

!!! info "Status: From the data"
    Read straight from game files or compared between builds. What the files contain is checked; why they are that way (developer intent) is interpretation. See [status labels](../status-labels.md).

Summary for the author, 2026-10-28. "v1.00" = the US disc BLUS41045 (the Asian disc is the same game byte for byte; the EU
disc is not checked). "Gone by 1.03" = what patch 1.03 loads (1.03's PatchData over the v1.00 disc) no longer has it,
or no longer uses it. "Network Test" = the US test NPUB90979 (`DS2_GAME=nt`), whose text matches the Japanese test.

Method: every file, regulation param row and Japanese / English text entry that differs between v1.00 and 1.03 was
checked against the Network Test (scratch scripts `v100_gone_vs_nt.py`, `checks2.py`, `checks3.py`, `entalk.py`, not
kept; sources `v1.00-vs-1.01.md`, `1.01-to-1.03.md`, `cut-talk-timeline.md`, `..\..\DS2 Japan\findings\jp-disc-vs-us.md`).
294 files, 64 param rows and 174 text entries differ.

**Short answer: not much.** The well-known cut text that 1.03 stopped shipping (the girl + dealer questline, the old
Shanalotte lines, the cutscene test text) was already in the Network Test, so it falls outside. What is left is
below.

## Not counted, and why

- **Already in the Network Test**: the 51 text files 1.03 stops shipping (m20_04 girl + dealer, m10_21 old Shanalotte,
  m90_00 cutscene test text, m99_97, `bofireName.fmg` "テスト"); the other 30 EnemyParam rows 1.03 removes (8100,
  9100-9613); the m10_03 / m10_11 online-area rows; enemy bullet 191701110; the four item-lot params 1.03 drops from
  the regulation.
- **Not really gone**: the menu copy of "The letters are worn beyond recognition." (`regulation.fmg`, new in v1.00,
  not re-shipped by 1.03) also lives in the regulation binder, which 1.03 keeps; and a patch cannot delete disc files,
  so every 1.03-dropped file stays on the disc, just unused.
- **Balance, not content**: Chloranthy Ring, Green Blossom, Licia's and Demon of Song's stats, the 1.02 and 1.03
  balance passes.
- **Fixes**: text typos and corrections (Imperious set "long ago long ago", Dark bonus "higher" -> "lower", Northern
  Ritual Band, Ornifex's ヴェンドリック -> ヴァンクラッド, the mistranslated "Insufficient stats..." ring message, whose
  correct English the test already had), collision re-bakes, bonfire flags.
- **Map, event and AI script versions**: the test ships one map's data (m10_23), so "not in the test" means nothing
  for these. 1.01's AI changes were all additions as far as the state-name comparison shows (no ESD decoder yet).
