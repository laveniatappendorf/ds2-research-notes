# Dark Souls II research notes

Unofficial working notes from taking Dark Souls II apart: the 2013 PlayStation 3 Network Test, the retail discs,
the patches and the PC *Scholar of the First Sin* build.

Read it at **https://laveniatappendorf.github.io/ds2-research-notes/** (once published).

These are research notes, not a player guide, and not everything has been checked twice. Each page carries a status
label. Corrections and test results are welcome as issues.

Text is shared under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Dark Souls is the property of
FromSoftware and Bandai Namco; this project is unofficial. No game files are included.

To preview locally: `pip install mkdocs-material` then `mkdocs serve`.
